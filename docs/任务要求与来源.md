## 需要明确的差异

- **人数**：石墨写 3 人一组，PPT 第 43 页写 2 人。以石墨中的具体作业要求整理，若教师另有通知应按教师要求调整。
- **完整性**：PPT 第 40 页以 CBC 链式变化引出完整性和 MAC。本实验不会把普通 CBC 加解密当作认证机制。实际篡改首个密文分组后，PKCS#7 仍可有效，说明单靠填充/错误传播不足以认证消息。
- **ASCII 密文**：原文把 ASCII 拼成 ASII/ACII。明文按标准 ASCII 编码；密文是任意字节，用 Latin-1 一一对应和 JSON 转义承载。HEX 是更便于交换的表示形式。
- **实现语言/GUI**：原文列举 C++/Qt、Java/Swing、Python/Qt 等并允许选择熟悉的语言；本实现采用 Python 标准库和本地浏览器 GUI。
- **三重模式**：石墨未强制 EEE/EDE。本实验采用第 9 讲 EDE 构造，并明确 32-bit 模式 `K3=K1`，48-bit 模式独立 `K3`。
- **截止时间**：石墨与 PPT 均为 `2026.10.31 23:00`，未标明时区。

原课件与教材扫描件不复制进公开仓库。算法常数和教学算例已在开发手册与测试代码中注明来源。
