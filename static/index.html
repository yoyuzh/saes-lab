关卡 03 / 扩展功能

以两个字节为一组

处理 ASCII 字符串，保留每个字节，包括空格和末尾的零字节。

字符串加解密

字节约定

每 2 个 ASCII 字符组成一个 16-bit 分组，前一个字节为高位。

A41B424142

可逆填充

采用 2 字节分组的 PKCS#7：奇数长度补 01，偶数长度补 02 02。空字符串也补一个完整分组。

如何表示乱码密文

任意密文字节可能超出 ASCII。界面同时输出十六进制和可逆的字节字符转义表示，下载 JSON 可保留原始 Latin-1 字符。
